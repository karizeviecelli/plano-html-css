## Ementa

Fundamentos de construção de páginas web. Linguagem HTML: estrutura, elementos semânticos, formulários, tabelas e multimídia. Linguagem CSS: seletores, propriedades, box model, flexbox, grid, responsividade e animações. Integração de interfaces web com dispositivos robóticos. Projeto final de um painel de controle para robô.

---

## Objetivos Pedagógicos

### Objetivo Geral

Capacitar o estudante a projetar e desenvolver interfaces web completas utilizando HTML e CSS, aplicando esses conhecimentos na criação de painéis de controle para sistemas robóticos.

### Objetivos Específicos

1. Compreender a estrutura e a semântica de documentos HTML.
2. Utilizar elementos HTML para exibir texto, imagens, tabelas, formulários e conteúdo multimídia.
3. Aplicar estilos CSS para controlar aparência, espaçamento, cores e tipografia.
4. Construir layouts flexíveis e responsivos com Flexbox e CSS Grid.
5. Incorporar animações e transições para melhorar a experiência do usuário.
6. Desenvolver uma interface funcional para monitoramento e comando de um robô simulado.

## Conteúdo Programático (Ementa Detalhada)

### 1. Fundamentos do HTML
- Estrutura básica de um documento HTML (``, ``, ``, ``)
- Tags de título (`` a ``), parágrafo (``), quebra de linha (``)
- Ênfase e destaque com `` e ``
- Hiperligações (``) e caminhos absolutos/relativos
- Imagens (``) e atributos `src`, `alt`, `width`, `height`
- Listas ordenadas (``) e não ordenadas (``)

### 2. HTML Semântico e Estrutura
- Elementos estruturais: ``, ``, ``, ``, ``, ``, ``
- Tabelas: ``, ``, ``, ``, ``, ``
- Formulários: ``, ``, ``, `<select>`, `<button>`, atributos `action`, `method`, `name`<br/>
- Multimídia: `<video>`, `<audio>`, `<iframe>`

### 3. Introdução ao CSS
- Formas de inclusão: inline, interno (`<style>`) e externo (`<link>`)<br/>
- Seletores: de tag, classe (`.`), id (`#`), universal (`*`), descendente, filho (`>`)<br/>
- Propriedades básicas: `color`, `background-color`, `font-family`, `font-size`, `text-align`<br/>
- Unidades: `px`, `%`, `em`, `rem`, `vh`, `vw`

### 4. Box Model e Espaçamento
- Conceito de box model: `content`, `padding`, `border`, `margin`<br/>
- Propriedades: `width`, `height`, `padding`, `margin`, `border`<br/>
- `box-sizing: border-box;`<br/>
- `display`: `block`, `inline`, `inline-block`, `none`

### 5. Layout com Flexbox
- Propriedades do container: `display: flex`, `flex-direction`, `justify-content`, `align-items`, `flex-wrap`, `gap`<br/>
- Propriedades dos itens: `flex`, `flex-grow`, `flex-shrink`, `flex-basis`, `align-self`, `order`<br/>
- Exemplos práticos: centralização, barra de navegação, grade de cards

### 6. Layout com CSS Grid
- Definição: `display: grid`, `grid-template-columns`, `grid-template-rows`, `gap`<br/>
- Posicionamento: `grid-column`, `grid-row`, `grid-area`<br/>
- Áreas nomeadas: `grid-template-areas`
- Comparação entre Flexbox e Grid

### 7. Responsividade e Media Queries
- Conceito de design responsivo
- Sintaxe de media queries: `@media (max-width: 768px) { ... }`
- Breakpoints comuns (480px, 768px, 1024px)
- Imagens fluídas e unidades relativas

### 8. Animações e Transições
- Transições CSS: `transition-property`, `transition-duration`, `transition-timing-function`<br/>
- Animações com `@keyframes`: `animation-name`, `animation-duration`, `animation-iteration-count`<br/>
- Exemplos: hover, carregamento, destaque de elementos

### 9. Integração com Robótica
- Criação de painel de controle para robô simulado
- Botões de comando (frente, trás, esquerda, direita, parar)
- Indicadores de status (LEDs, sensores, bateria)
- Uso de formulários para enviar parâmetros (velocidade, tempo)
- Estilização temática (cores metálicas, fontes tecnológicas)
